Cómo escanear código de barras con el celular en tu kiosco

Muchos dueños de kioscos creen que para escanear productos necesitan comprar una pistola lectora de códigos de barras. La realidad: la cámara de tu celular ya es un lector de códigos de barras — solo necesitás el sistema correcto.

¿Por qué el celular reemplaza a la pistola de escaneo?

Las pistolas de escaneo tradicionales (esos aparatos con forma de pistola que se conectan por USB) cuestan entre $30.000 y $120.000 pesos, necesitan un cable o adaptador para el celular, y si se rompen o las perdés, tenés que comprar otra.

La cámara trasera de cualquier celular moderno puede leer códigos de barras EAN-13 (el estándar en Argentina) en menos de un segundo, con buena iluminación. Para un kiosco o almacén con menos de 500 ventas diarias, es más que suficiente.

Paso a paso: cómo escanear productos en MiNegocio

  1. Abrí el punto de venta en MiNegocio (desde el navegador del celular).
  2. Tocá el ícono de cámara en el campo de búsqueda de productos.
  3. Apuntá la cámara al código de barras del producto — mantené el celular a unos 15-20 cm de distancia.
  4. El producto aparece automáticamente en el carrito con su precio actualizado.
  5. Si es la primera vez que escaneás ese producto, el sistema te pide el precio y lo guarda para las próximas veces.

💡 Tip: Si el código no lee bien, limpiá la lente de la cámara con la manga del buzo. La mayoría de los problemas de lectura son por suciedad en la lente, no por el código.

¿Qué pasa si un producto no tiene código de barras?

No todos los productos tienen código de barras. Los artículos de almacén sin envase industrial (facturas, productos a granel, artículos de elaboración propia) no lo tienen. En ese caso tenés dos opciones:

  • Buscar por nombre: escribís las primeras letras y el sistema sugiere el producto.
  • Crear un código propio: MiNegocio te permite asignar un código de barras personalizado (podés imprimir una etiqueta y pegarla en el producto).

Escaneado para actualizar precios

El escaneo no sirve solo para vender — también podés usarlo para actualizar precios rápidamente. Cuando llega una nueva lista de precios del proveedor, en vez de buscar cada producto por nombre, escaneás el código de barras y el sistema muestra el precio actual para que lo modifiques.

Si tenés muchos productos para actualizar a la vez, la importación desde Excel sigue siendo la opción más rápida — pero para actualizaciones puntuales, el escaneo es imbatible.

Escaneado para recibir mercadería

Cuando llega el pedido del proveedor, podés escanear cada artículo recibido para sumar las unidades al stock. MiNegocio va sumando las cantidades conforme escaneás, sin que tengas que anotar nada.

¿Y si tengo varios empleados?

MiNegocio permite que cada empleado use su propio celular como punto de venta. Los productos escaneados en cualquier dispositivo quedan registrados en la misma cuenta, con el nombre del operador que hizo la venta. Al final del turno, el arqueo de caja muestra las ventas de todos los dispositivos juntas.
