Como funciona un acopio?

Es una compra por adelantado con retiro diferido. El cliente paga (o se le asigna a su cuenta corriente) una cantidad de materiales y los retira en parciales. El sistema controla cada retiro y mantiene el saldo actualizado.

El stock se descuenta al crear el acopio o al retirar?

Al retirar. El acopio es una reserva, pero el stock fisico sigue en tu deposito hasta que el cliente lo retira. Solo se descuenta del inventario cuando registras el retiro parcial.

Puedo facturar un acopio?

Si. Al crear el acopio podes emitir un presupuesto o una factura por el total. Despues, cada retiro genera su remito correspondiente.
