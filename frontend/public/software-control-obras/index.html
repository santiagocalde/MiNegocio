El problema de no tener control de obras

Sin sistema

Anotas las obras en un cuaderno o en planillas sueltas. Cuando un cliente pregunta cuanto lleva gastado, tenes que sumar tickets y presupuestos a mano. Las obras terminadas se mezclan con las activas.

Con MiNegocio

Cada cliente tiene su lista de obras. Cada presupuesto y remito se asigna a una obra especifica. Sabes al instante cuanto gasto cada obra, que materiales se entregaron y cuales faltan.

"Tengo 15 obras activas entre todos mis clientes. Antes era un caos. Ahora entro al sistema y veo todo ordenado: que se entrego, que falta, cuanto gasto cada una." -- Corralon del GBA

Funcionalidades

Que podes hacer con el control de obras

🏗

Obras activas y terminadas

Cada obra tiene un estado: activa o terminada. Las activas aparecen primero. Al terminar la obra, la marcas y se archiva ordenadamente.

📄

Presupuestos por obra

Al crear un presupuesto, elegis a que obra y cliente pertenece. El sistema mantiene el historial completo de cada obra.

🚚

Remitos vinculados

Cuando entregas materiales, el remito queda asociado a la obra. Sabes exactamente que se entrego y cuando.

➕

Crear obra desde el cliente

Desde la ficha del cliente, un boton "+ Agregar obra" para crear una nueva obra al instante. Sin navegar a otro modulo.

Puedo tener varias obras por cliente?

Si, sin limite. Un cliente puede tener multiples obras activas (ej: "Casa Martinez", "Local Centro", "Departamento Belgrano"). Cada una con sus propios presupuestos y remitos.

Como se cuales obras estan activas?

El modulo de Obras muestra primero las activas con un indicador visual. Las obras terminadas quedan en una seccion aparte. Podes filtrar por estado.

Se puede ver cuanto gasto cada obra?

Si. Cada obra acumula los presupuestos aprobados y los remitos entregados. Podes ver el total gastado en materiales de cada obra en tiempo real.
