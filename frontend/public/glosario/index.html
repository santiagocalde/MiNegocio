Glosario de gestión comercial

Términos clave para kioscos, almacenes y comercios de barrio en Argentina. Desde el arqueo de caja hasta la facturación electrónica.

Impuestos

ARCA (ex AFIP)

La agencia recaudadora del Estado argentino. Sucesor de la AFIP que administra la facturación electrónica y el Monotributo.

 Gestión

Arqueo de caja

El proceso de contar el efectivo del cajón al cierre del turno y compararlo con lo que el sistema dice que debería haber.

 Ventas

Catálogo web

Página pública donde tus clientes ven todos tus productos y precios desde el celular, sin necesidad de descargar nada.

 Inventario

Código de barras

El conjunto de líneas negras en el envase de cada producto. Escaneándolo con el celular registrás ventas en segundos.

 Inventario

Control de stock

El seguimiento en tiempo real de cuánto tenés de cada producto. Evita faltantes, detecta merma y mejora la rentabilidad.

 Clientes

Cuenta corriente

El registro organizado de lo que cada cliente te debe. El sistema de fiados de toda la vida, pero sin papeles ni cuadernos.

 Impuestos

Factura electrónica

El comprobante fiscal que se valida en tiempo real contra ARCA antes de entregárselo al cliente. Obligatoria desde 2019.

 Clientes

Fiado

Vender sin cobrar en el momento, con la promesa de pago posterior. La práctica del comercio de barrio, manejada con sistema.

 Inventario

Inventario

El registro de todos los productos con sus cantidades y precios. La base para no quedarte sin mercadería ni acumular lo que no rota.

 Ventas

Lista de precios

El catálogo de lo que cobrás por cada producto. Incluye precio minorista, mayorista y cómo actualizarlos masivamente.

 Finanzas

Margen de ganancia

La diferencia entre el costo y el precio de venta de cada producto. Lo que realmente ganás con cada unidad vendida.

 Impuestos

Monotributo

El régimen simplificado de ARCA para pequeños contribuyentes. Cuota fija mensual y facturación tipo C.

 Gestión

Multi-negocio

La posibilidad de manejar más de un local desde una sola cuenta. Ventas, stock y reportes de cada sucursal en un lugar.

 Tecnología

POS offline

Sistema de punto de venta que funciona sin internet y sincroniza con la nube cuando vuelve la conexión.

 Tecnología

Punto de venta

El sistema donde se registran las ventas, se cobra al cliente y se actualiza el stock. El corazón de tu negocio.

 Tecnología

Sistema POS

El software que usás para vender, cobrar y gestionar tu negocio. Guía completa para elegir el mejor para tu rubro.

 Tecnología

Software de gestión

Integra el POS con el control de stock, las finanzas y los reportes. Más que un sistema de cobro.

 Ventas

Ticket de venta

El comprobante que le entregás al cliente por cada compra. Diferencia con la factura y qué datos debe incluir.
